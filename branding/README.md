# FRAKON Brand Assets

This directory contains the source and generated brand assets for FRAKON OS and FRAKON Energy.

Generated outputs include:

- SVG source files
- PNG icons and horizontal logos
- ICO favicons
- GitHub avatars
- iOS/Android app icons
- web favicon sizes
- Home Assistant custom integration brand files
- dark and light variants

The Home Assistant files are generated into:

`custom_components/frakon_energy/brand/`
