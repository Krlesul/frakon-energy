# FRAKON Energy roadmap

## 0.1 – Foundation

- samostatný Home Assistant repozitář
- provider-independent core
- datově řízené ceníky s platností od data
- základ config flow

## 0.2 – VisionQ

- oficiální API, pokud jej VisionQ poskytne
- alternativní e-mail/heslo provider
- automatická obnova relace
- VT, NT, celkem, dnešní spotřeba a diagnostika

## 0.3 – HDO

- adaptér na integraci ČEZ HDO
- aktivní tarif
- rozvrh a živý odpočet

## 0.4 – Pricing and costs

- více historických a budoucích ceníků
- automatická aktivace podle data
- variabilní a stálé náklady
- zpětný přepočet z dostupné historie spotřeby

## 0.5 – Dashboard and HACS

- entity a karty pro dashboard
- Energy Dashboard kompatibilita
- HACS instalace a aktualizace

## Later

- fotovoltaika
- bateriová úložiště
- wallboxy
- elektromobily
- lokální API pro FRAKON OS
